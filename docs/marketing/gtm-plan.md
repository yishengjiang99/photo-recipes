# Photo Recipes — Go-to-Market Plan

## Product

Mobile-friendly web app of photography **field presets** (HDR, panning, depth of field, motion blur, low angle) plus **Ask Grok** for scene-specific recipes.

| Tier | What you get | Price |
| --- | --- | --- |
| **Free Peek** | Browse all recipes + **1 Ask/day** | Free |
| **Pro** (primary CTA) | Unlimited Ask + field checklists | **$7.99/mo** or **$59.99/yr** |
| Trial | Full Pro | **7-day trial** (push yearly) |

Payments: Stripe. Repo: [yishengjiang99/photo-recipes](https://github.com/yishengjiang99/photo-recipes).

---

## 1. Positioning

### One-liner

> **Photo Recipes turns classic shooting techniques into field-ready presets — describe the scene (or soon, upload a photo) and get the recipe to shoot it.**

### Category

Field assistant for **camera technique** — not an editor, not a filter pack, not a course.

### Value props

| Prop | Meaning |
| --- | --- |
| **In the moment** | Use it when you're standing in the light with the wrong settings |
| **Technique, not filters** | Dials, steps, gear checklists — real shooting recipes |
| **Ask, don't dig** | Describe the scene; get the matching recipe |
| **Soft try** | Browse free; one Ask/day free; Pro when you need unlimited |

### Differentiation

| Alternative | Why Photo Recipes wins |
| --- | --- |
| Lightroom / editors | We don't edit; we tell you how to **shoot** |
| YouTube / courses | Great for learning; useless when the light is fading |
| ChatGPT | Generic; we ship structured field presets + checklists |
| Static cheat sheets | Static can't match *this* scene; Ask can |

### Do / Don't language

| Do | Don't |
| --- | --- |
| Field checklist language ("steps, dials, gear") | "AI photography" as the headline |
| Technique / recipe / preset | Position as a Lightroom alternative |
| Soft try / Free Peek | Lead with book origin or author story |

## 2. Ideal Customer Profile (ICP)

**Core:** Enthusiast with a **real camera** who has moved past Auto.

| Priority | Segment | Why |
| --- | --- | --- |
| **P0** | Travel / landscape shooters + workshop alumni | Highest intent in the field; already paid to learn technique |
| **P1** | Street / action + phone→camera upgraders | Need fast recipes under pressure |
| **P2** | Educators / instructors | Multiplier: assign recipes to students |
| **Deprioritize** | Working pros; pure phone-only shooters | Pros have systems; phone-only ≠ our preset language yet |

## 3. Channels

| Channel | Role | Notes |
| --- | --- | --- |
| Reddit | Primary community | Specific subs (r/photography, r/AskPhotography, r/landscape, travel photo, etc.) — value-first, no spam |
| Discord | Community depth | Photo Discords; hang out before pitching |
| Facebook groups | Local / workshop alumni | Soft share + magnet |
| SEO technique pages | Long-term acquisition | One page per technique (HDR, panning, DoF…) |
| Short video | Awareness | Hooks from ad plan; Reels/Shorts/TikTok organic first |
| Micro-creators (5k–80k) | Trust + demos | Paid or gifted Pro; authentic field use |
| Workshop instructors | High-intent referrals | Bundle recipes into post-workshop follow-up |
| Newsletters | Credibility | PetaPixel-class, regional photo newsletters |

### Skip (early)

- **App Store** — web first; store tax + delay not worth it yet
- **Google Ads** — hold until SEO technique pages convert organically

## 4. Funnel

```
Awareness → Browse recipes → First Ask (activation) → Paywall → 7-day trial (yearly) → Paid
```

| Stage | Metric | Target |
| --- | --- | --- |
| Visit → Ask | Activation rate | **25–40%** |
| Ask → Trial | Conversion | **8–15%** |
| Trial → Paid | Paid conversion | **25–40%** |

**Activation definition:** user completes their **first Ask** (not just browse).

## 5. Week 0–8 launch sequence

| Phase | Weeks | Focus |
| --- | --- | --- |
| **Foundations** | 0–1 | Analytics, Ask above fold, Stripe trial path, UTMs, core recipe catalog |
| **Seed** | 1–2 | Soft share to warm contacts; 5 Field Recipes PDF magnet; first outreach list |
| **Content** | 2–4 | SEO technique pages; short-video hooks; Reddit value posts (no hard sell) |
| **Community** | 3–5 | Discord/FB hangouts; workshop instructor emails; micro-creator outreach |
| **Soft launch** | 5–6 | Broader community posts; first small Meta test if organic Asks ≥30/14d |
| **Vision** | 6–7 | Photo-upload Ask preview messaging; yearly CTA emphasis |
| **Decide** | 7–8 | Kill/scale channels; double down on what moved Weekly Activated Users |

## 7. North-star & kill/scale

**North-star metric:** **Weekly Activated Users** (users who completed ≥1 Ask in the week).

| Signal | Action |
| --- | --- |
| WAU up week-over-week + Trial→Paid ≥25% | Scale winning channel |
| Visit→Ask <15% for 2 weeks | Fix product/UX before more ads |
| CPA-Ask >$3 after 50 paid clicks | Kill that ad set |
| Trial→Paid <15% after 30 trials | Fix paywall/offer, not spend more |

---

## 8. Risks & time wasters

| Risk | Mitigation |
| --- | --- |
| Thin catalog | Ship P0 recipes first; quality over breadth |
| Book optics | Don't lead with book; lead with field utility |
| "AI wrapper" perception | Emphasize presets + checklists; Ask as assistant, not the product |
| App Store early | Skip until web converts |
| Lightroom-comparison ads | Wrong category; confuses buyers |
| Social features early | Distraction; focus Ask → trial |

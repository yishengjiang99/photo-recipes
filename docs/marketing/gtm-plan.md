# Photo Recipes — Go-to-Market Plan

**Revision (2026-09-19):** **iOS-first** GTM. Growth surface = **TestFlight / App Store**. Web feature work paused — do not lead paid or organic traffic to a deep web app. Activation = first **Auto Optimize** (not Ask). Copy source of truth: [ad-copy-v2.md](./ad-copy-v2.md).

## Product

Agentic **field camera on iPhone** — Point → **Auto Optimize** writes shutter / ISO / EV / WB / focus (plus expanded levers selectively) on the live viewfinder; optional **field looks** = capture grades (not beauty filters). Voice secondary.

| Tier | What you get | Price |
| --- | --- | --- |
| **Free Peek** | Browse recipes + **1 Auto Optimize/day** | Free |
| **Pro** (primary CTA) | Unlimited Auto Optimize + manual dials + Teach mode + checklists | **$7.99/mo** or **$59.99/yr** |
| Trial | Full Pro | **7-day trial** (push yearly) |

Payments: **iOS IAP** (StoreKit). Repo: [yishengjiang99/photo-recipes](https://github.com/yishengjiang99/photo-recipes).

## 1. Positioning

### One-liner (LOCKED)

> Point your phone at the shot — Photo Recipes Auto Optimizes shutter, ISO, and focus so you capture the technique, not fix it later.

### Slogan

**Set the shot. Then take it.**

### Category

Agentic field camera + photography skill library for **high-end photography enthusiasts** — not an editor, not a filter pack, not a chat toy.

### Value props

| Prop | Meaning |
| --- | --- |
| **From viewfinder** | Point at the shot; Auto Optimize applies dials on device |
| **Technique, not filters** | Shutter / ISO / EV / WB / focus; field looks = capture grades |
| **Capture grades** | Optional looks on viewfinder + capture (intensity 0–1); ORIGINAL names only |
| **Soft try** | Free Peek 1 AO/day; Pro when you need unlimited + Teach |

### Differentiation

| Alternative | Why Photo Recipes wins |
| --- | --- |
| Lightroom / editors | We don't edit; we set dials **before** you shoot |
| Filter / beauty apps | Capture grades ≠ beauty filters; ICP is enthusiasts with real cameras |
| YouTube / courses | Great for learning; useless when the light is fading |
| ChatGPT | Generic; we write real camera settings on iPhone |
| Static cheat sheets | Static can't match *this* scene; Auto Optimize can |

### Do / Don't language

| Do | Don't |
| --- | --- |
| Point → Auto Optimize → Ready; TestFlight / App Store CTAs | Lead with Ask / voice / deep web app |
| Shutter, ISO, EV, WB, focus; field looks as capture grades | AI magic, beautify, sky replacement, IG/CapCut look names |
| Slogan **Set the shot. Then take it.** | Sense·Reason·Apply as marketing slogan |
| Free Peek · Pro $7.99/$59.99 · 7-day trial · iOS IAP | Stripe-first / web paywall as primary story |

## 2. Ideal Customer Profile (ICP)

**Core:** High-end photography enthusiasts — serious hobbyists with a **real camera** who use the phone as a companion field tool. Not casual filter users.

| Priority | Segment | Why |
| --- | --- | --- |
| **P0** | Travel / landscape shooters + workshop alumni | Highest intent in the field; already paid to learn technique |
| **P1** | Street / action + phone→camera upgraders who still carry gear | Need fast dials under pressure |
| **P2** | Educators / instructors | Multiplier: assign recipes / TestFlight to students |
| **Deprioritize** | Working pros with rigid systems; beauty / filter shoppers | Wrong category fit |

## 4. Funnel

```
Awareness → Install / TestFlight → First Auto Optimize (activation) → 7-day trial → Paid (IAP)
```

| Stage | Metric | Target |
| --- | --- | --- |
| Install → first Auto Optimize | Activation rate | **25–40%** |
| Auto Optimize → Trial | Conversion | **8–15%** |
| Trial → Paid | Paid conversion | **25–40%** |

**Activation definition:** user completes their **first Auto Optimize** (not Ask, not browse-only).

## 5. Week 0–8 launch sequence

| Phase | Weeks | Focus |

| **Foundations** | 0–1 | Analytics (install → AO → trial → paid), TestFlight / StoreKit path, UTMs, App Store listing draft |

| **Decide** | 7–8 | Kill/scale channels; double down on what moved Weekly Activated Users |

## 7. North-star & kill/scale

**North-star metric:** **Weekly Activated Users** (users who completed **≥1 Auto Optimize** in the week).

| Signal | Action |
| --- | --- |
| WAU up week-over-week + Trial→Paid ≥25% | Scale winning channel |
| Install→AO <15% for 2 weeks | Fix onboarding / Auto Optimize UX before more ads |
| CPA-install or CPA-AO above kill after 50 paid clicks | Kill that ad set |
| Trial→Paid <15% after 30 trials | Fix paywall/offer (IAP), not spend more |

---

## 8. Risks & time wasters

| Risk | Mitigation |
| --- | --- |
| Thin catalog / weak AO loop | Ship core levers + Teach; quality over breadth |
| Book optics | Don't lead with book; lead with field utility |
| "AI filter" perception | Emphasize dial writes + capture grades; never beauty framing |
| Web-first distraction | Keep growth on iOS / TestFlight / App Store |
| Lightroom-comparison ads | Wrong category; confuses buyers |
| Voice / Ask as primary story | Voice secondary; Ask is not activation |

# Articles

Articles on photo.grepawk.com are generated from the `articles/` folder: one folder per article
(`articles/<slug>/article.html` with front matter + HTML), built into static pages under `/articles` by
`scripts/prerender-articles.mjs` during `npm run build`. The same folder drives the `/articles` index, the home
page feature card, the nav/footer link and the sitemap entries submitted to IndexNow after deploy.

How to add one, the front matter fields and the template: [articles/README.md](../articles/README.md)
(template folder: `articles/_template/`).

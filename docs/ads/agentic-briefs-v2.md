# Agentic creative briefs v2 — Auto Optimize

**ICP:** High-end photography enthusiasts / workshop alumni with real cameras (and phone as field assistant). Craft-forward tone — tabular/mono dial readouts, Darkroom quiet, **craft over vibes**. Not lifestyle-filter ads, not beauty, not soft bokeh “pro look” promises.

**Copy:** Marketing Expert [`ad-copy-v2.md`](../marketing/ad-copy-v2.md) — **verbatim** when present on main. Pairing: [`copy-pairing-v2.md`](./copy-pairing-v2.md).

**On-device (before→after chips ONLY):** shutter / exposure duration · ISO · EV bias · WB · focus lock/POI. Zoom/lens optional when device allows — never required.  
**Coach-only (never fake as applied):** aperture · ND · tripod — end card or Teach once only.

**Visual system (Darkroom field notes):** bg `#0c0c0f` · surfaces `#141418` / `#1c1c22` · ink `#fafafa` · muted `#a1a1aa` · accent `#f43f5e` · fonts DM Sans + Instrument Serif · **mono/tabular** for dial values.

**Must show:** Auto Optimize rose pill · status · before→after **settings dials** (shutter·ISO·EV·WB·focus) · pan cues / From viewfinder + mic when relevant.  
**Must NOT:** filter/beauty before-after, AI-magic chrome, App Store badges, book branding, Shop Now.

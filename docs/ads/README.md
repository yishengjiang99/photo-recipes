# Photo Recipes — Ads package

Ad creatives and briefs for Meta / Reddit / short-form. Field technique positioning — not filters, not AI magic, no book branding, no App Store badges.

## Layout in repo

- `assets/ads/c3/` — C3 Recipe card UI statics (PNG)
- `docs/ads/` — briefs, idea dump, production notes

## C3 variants

| File prefix | Content |
|-------------|---------|
| `c3-library-*` | Recipe library with Panning hero |
| `c3-detail-*` | Full panning recipe + dials |
| `c3-dials-*` | Dial close-up |
| `c3-checklist-*` | Field gear checklist |

Sizes: `1080x1350` (4:5), `1080x1080` (1:1), `1080x1920` (9:16).
